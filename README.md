# andresfgzdev skills

Agent skills for **understanding** and **organising** codebases. They work in Claude Code as plugins, and in any agent that reads [Agent Skills](https://agentskills.io) (Codex, Cursor, Copilot and others).

```text
/plugin marketplace add andresfgzdev/skills
```

---

## [explain-it](https://github.com/andresfgzdev/explain-it)

**Explains how a feature, API or multi-system flow works.** It traces the real code path from ingress through checks and processing to storage, including every place the flow can fail. It writes the explanation in ASD-STE100 (Simplified Technical English) at the depth you ask for, and draws the whole system as an SVG overview plus an interactive walkthrough.

[![System overview generated by explain-it](https://raw.githubusercontent.com/andresfgzdev/explain-it/main/docs/overview.svg)](https://github.com/andresfgzdev/explain-it)

> *"Explain how the Salesforce webhook reaches our database."* · *"How does PaymentForm talk to the backend? High tier."*

```text
/plugin install explain-it@andresfgzdev
```

---

## [tidy-tree](https://github.com/andresfgzdev/tidy-tree)

**Finds and fixes where code lives in JS/TS repositories, by your project's own architecture.** It looks for grab-bag files, duplicates, misplaced and dead files, layer-crossing imports and import cycles. It shows each candidate in an interactive HTML review, then applies only what you approve, with every import rewired and type-checked.

> *"Our `utils` folder is a mess, tidy it."* · *"Find duplicated helpers."* · *"Where should this hook live?"*

```text
/plugin install tidy-tree@andresfgzdev
```

## Other ways to install

Each skill also installs on its own:
- **One marketplace per skill:** `/plugin marketplace add andresfgzdev/<skill>`.
- **Any agent, through the [`skills`](https://github.com/vercel-labs/skills) CLI:** `npx skills add andresfgzdev/<skill>`.
- **By hand:** copy the skill's `skills/<skill>/` folder.

Each repository's README covers requirements and limits.
